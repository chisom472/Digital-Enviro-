C++

Fine-grained control over memory and performance — the language behind game engines, operating systems, and high-frequency software.

1. Syntax & variables

#include <iostream>

int main() {
  int score = 10;
  std::string username = "chisom";

  score = score + 5;
  std::cout << score << std::endl;      // 15
  std::cout << username << std::endl;   // chisom
  return 0;
}
Try it: paste this into the playground's C++ mode to see sample output.

2. Functions

int add(int a, int b) {
  return a + b;
}

int main() {
  int result = add(2, 3); // 5
  std::cout << result << std::endl;
  return 0;
}

Every C++ function has an explicit return type — void if it returns nothing.

3. Pointers & references

int score = 10;
int* scorePtr = &score;   // pointer holds an address
int& scoreRef = score;    // reference is an alias

*scorePtr = 20;  // changes score through the pointer
scoreRef = 30;   // changes score through the reference

std::cout << score << std::endl; // 30

Pointers store a memory address; references are a safer alias to an existing variable. This is the concept most beginners find hardest — take it slowly.

4. Memory management

int* nums = new int[5];  // allocate on the heap
nums[0] = 1;
nums[1] = 2;

delete[] nums;  // free the memory when done
Forgetting delete causes a memory leak. Modern C++ favors smart pointers (std::unique_ptr, std::shared_ptr) that clean up automatically.

5. Classes

class Learner {
  public:
    std::string name;
    std::string level;

    Learner(std::string n, std::string l) : name(n), level(l) {}

    std::string greet() {
      return name + " is a " + level + " developer.";
    }
};

Learner ada("Ada", "beginner");
std::cout << ada.greet() << std::endl;

The : name(n), level(l) syntax is a constructor initializer list — the idiomatic way to set fields when an object is created.
