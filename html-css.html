HTML & CSS

Every web page starts here: structure with HTML, style and layout with CSS. This track builds up to full responsive pages.

1. HTML document structure

Every HTML page follows the same skeleton: a doctype, a head for metadata, and a body for visible content.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Page</title>
</head>
<body>
  <h1>Hello, world</h1>
</body>
</html>
Try it: paste this into the playground's HTML mode and watch it render live.

2. Semantic elements

Semantic tags describe what content means, not just how it looks — better for accessibility and SEO.

<header>Site navigation</header>
<main>
  <article>
    <h2>Blog Post Title</h2>
    <p>Content goes here.</p>
  </article>
</main>
<footer>Copyright info</footer>

Screen readers and search engines both use these tags to understand a page's structure.

3. The CSS box model

Every element is a box made of content, padding, border, and margin — in that order, from inside out.

.card {
  padding: 20px;        /* space inside the border */
  border: 1px solid #ccc;
  margin: 16px;         /* space outside the border */
  box-sizing: border-box; /* padding & border included in width */
}
box-sizing: border-box is worth setting globally — it makes width calculations far more predictable.

4. Flexbox

Flexbox arranges items in a single row or column, distributing space between them.

.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

Use Flexbox for navigation bars, button groups, and any one-dimensional layout.

5. CSS Grid

Grid handles two-dimensional layout — rows and columns together.

.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

@media (max-width: 600px) {
  .gallery { grid-template-columns: 1fr; }
}

Try both examples in the playground's CSS mode against the sample .box element.

6. Responsive design

Media queries adapt layout to screen size, and relative units keep things flexible.

.container {
  width: 100%;
  max-width: 1180px;
  margin: 0 auto;
  padding: 0 clamp(16px, 4vw, 40px);
}

Design mobile-first: style the small-screen layout by default, then add complexity inside larger min-width media queries.
