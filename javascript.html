JavaScript

The language that runs in every browser — and, with Node.js, on servers too. This track takes you from variables to working with real data in the DOM.

1. Variables & data types

Variables store values you can use and change later. Modern JavaScript uses let for values that change and const for values that don't.

let score = 10;
const username = "chisom";

score = score + 5; // OK — let can change
// username = "new";  // Error — const can't be reassigned

console.log(typeof score);    // "number"
console.log(typeof username); // "string"

The core data types are numbers, strings, booleans, null, undefined, and objects (which include arrays and functions).

Try it: paste this into the playground and change the values.

2. Functions

Functions package up reusable logic. Arrow functions are the modern, concise syntax.

function add(a, b) {
  return a + b;
}

const multiply = (a, b) => a * b;

console.log(add(2, 3));       // 5
console.log(multiply(4, 5));  // 20

Functions can take default parameters and return early:

function greet(name = "friend") {
  if (!name) return "Hello!";
  return `Hello, ${name}!`;
}

3. Arrays & objects

Arrays hold ordered lists. Objects hold key-value pairs.

const languages = ["JavaScript", "Python", "SQL"];
languages.push("Java");

const user = {
  name: "Ada",
  role: "developer",
  skills: languages
};

console.log(user.name);        // "Ada"
console.log(languages.length); // 4
console.log(languages.map(l => l.toUpperCase()));

.map(), .filter(), and .reduce() are the three array methods you'll reach for most often — they transform data without writing manual loops.

4. Control flow & loops

for (let i = 0; i < 3; i++) {
  console.log("Iteration", i);
}

const nums = [1, 2, 3, 4, 5];
const evens = nums.filter(n => n % 2 === 0);
console.log(evens); // [2, 4]

if (evens.length > 0) {
  console.log("Found even numbers");
} else {
  console.log("No even numbers");
}

5. The DOM

The Document Object Model lets JavaScript read and change what's on the page.

const heading = document.querySelector("h1");
heading.textContent = "Updated by JavaScript";

document.querySelector("button").addEventListener("click", () => {
  alert("Button clicked!");
});
The playground's JavaScript mode runs in an isolated sandbox without a real page, so DOM examples are best explored in the HTML/CSS mode instead.

6. Async JavaScript

Many operations — fetching data, reading files — take time. async/await makes that code read top-to-bottom instead of nesting callbacks.

async function loadUser() {
  try {
    const response = await fetch("/api/user");
    const data = await response.json();
    console.log(data);
  } catch (err) {
    console.error("Failed to load:", err.message);
  }
}

Under the hood, await pauses the function until a Promise resolves, without blocking the rest of the page.
