Java

A strongly typed, object-oriented language behind enterprise systems and Android apps. This track covers the fundamentals of writing and structuring Java code.

1. Syntax & variables

Java is statically typed — you declare a variable's type up front, and it can't change.

int score = 10;
String username = "chisom";
boolean isActive = true;

score = score + 5;
System.out.println(score);     // 15
System.out.println(username);  // chisom
Try it: paste this into the playground's Java mode to see sample output.

2. Methods

public class MathUtils {
  public static int add(int a, int b) {
    return a + b;
  }
}

int result = MathUtils.add(2, 3); // 5

A method's signature — name, parameter types, and return type — must match exactly however it's called.

3. Classes & objects

public class Learner {
  private String name;
  private String level;

  public Learner(String name, String level) {
    this.name = name;
    this.level = level;
  }

  public String greet() {
    return name + " is a " + level + " developer.";
  }
}

Learner ada = new Learner("Ada", "beginner");
System.out.println(ada.greet());

Java constructors initialize an object's fields when you use new. Fields marked private can only be accessed through the class's own methods.

4. Collections

import java.util.ArrayList;
import java.util.List;

List<String> languages = new ArrayList<>();
languages.add("Java");
languages.add("Python");

for (String lang : languages) {
  System.out.println(lang);
}

ArrayList, HashMap, and HashSet are the collections you'll use most — resizable lists, key-value maps, and unique sets.

5. Control flow & loops

for (int i = 1; i <= 3; i++) {
  System.out.println("Step " + i);
}

int[] nums = {1, 2, 3, 4, 5};
for (int n : nums) {
  if (n % 2 == 0) {
    System.out.println(n + " is even");
  }
}
