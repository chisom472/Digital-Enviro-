1. Variables & data types

Python doesn't require you to declare a type — it figures it out from the value.

score = 10
username = "chisom"
is_active = True

score = score + 5
print(type(score))     # <class 'int'>
print(type(username))  # <class 'str'>

Core types: int, float, str, bool, list, dict, tuple, and None.

Try it: paste this into the playground's Python mode to see sample output.

2. Functions

def add(a, b):
    return a + b

def greet(name="friend"):
    return f"Hello, {name}!"

print(add(2, 3))     # 5
print(greet("Ada"))  # Hello, Ada!

Python supports default arguments, keyword arguments, and returning multiple values as a tuple: return a, b.

3. Lists & dictionaries

languages = ["Python", "JavaScript", "SQL"]
languages.append("Java")

user = {
    "name": "Ada",
    "role": "developer",
    "skills": languages
}

print(user["name"])          # Ada
print(len(languages))        # 4
print([l.upper() for l in languages])

That last line is a list comprehension — a compact way to build a new list from an existing one.

4. Control flow & loops

for i in range(3):
    print("Iteration", i)

nums = [1, 2, 3, 4, 5]
evens = [n for n in nums if n % 2 == 0]

if evens:
    print("Found even numbers:", evens)
else:
    print("No even numbers")

5. Working with files

with open("notes.txt", "w") as f:
    f.write("Digital Enviro lesson notes\n")

with open("notes.txt", "r") as f:
    print(f.read())

The with statement automatically closes the file when you're done, even if an error happens inside the block.

File I/O needs a real Python environment — it won't run in the browser playground.

6. Classes & objects

class Learner:
    def __init__(self, name, level="beginner"):
        self.name = name
        self.level = level

    def greet(self):
        return f"{self.name} is a {self.level} developer."

ada = Learner("Ada")
print(ada.greet())

Classes bundle data (attributes) and behavior (methods) together — the foundation of object-oriented Python.
